# APA 7 Quick Guide

## Basic Student Paper
1. Title page
2. Main text
3. References

## In-text citations
- Parenthetical: (Author, 2026)
- Narrative: Author (2026)
- Direct quote: (Author, 2026, p. 10)

## Reference example — webpage
Author, A. A. (Year, Month Day). *Title of page*. Website Name. URL

## Reference example — journal article
Author, A. A. (Year). Title of article. *Journal Name, volume*(issue), pages. DOI

## Writing checklist
- Answer the assignment question directly.
- Use clear paragraphs with one main idea each.
- Support factual claims with reliable sources when required.
- Cite sources in the text and include them in the reference list.
- Proofread before submitting.
