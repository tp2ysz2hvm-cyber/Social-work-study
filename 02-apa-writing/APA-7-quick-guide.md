# APA 7 Quick Guide

## Basic paper setup
- Use the font and spacing required by your instructor.
- Double-space unless told otherwise.
- Use clear headings to organize longer papers.
- Include a title page when required.
- Include a reference list for sources cited in the paper.

## In-text citations
### Paraphrase
Author and year: `(Smith, 2024)`

### Narrative citation
`Smith (2024) explains...`

### Direct quote
Include author, year, and page number when available: `(Smith, 2024, p. 12)`.

## Reference list basics
- Alphabetical by author surname.
- Use a hanging indent.
- Include DOI or URL when appropriate.
- Every source cited in the paper should appear in the reference list.

## Before submitting
- Check assignment instructions first.
- Confirm every in-text citation has a matching reference.
- Check spelling, grammar, headings, and formatting.
- Make sure your own analysis is clear and not buried under quotations.
