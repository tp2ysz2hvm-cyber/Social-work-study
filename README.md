# Social Work Study

A study and preparation repository for the Social Service Worker program.

## Main Sections

- `01-course-notes/` — class notes, concepts, readings, and summaries
- `02-apa-writing/` — APA 7 help, paper planning, citations, and assignment templates
- `03-client-skills/` — interviewing, active listening, boundaries, documentation, and practice scenarios
- `04-practicum/` — placement preparation, supervision notes, goals, and reflection templates
- `05-templates/` — reusable case notes, intake notes, reflection sheets, and study templates
- `06-study-tools/` — quizzes, flashcards, review questions, and exam prep

## Goal

Keep school material organized, practical, and easy to review. Add course-specific folders as the program begins.
